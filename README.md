## 📘 Descrição do Projeto

Um site responsivo, criado com **HTML5**, **CSS3**, **PHP**, **JAVA SCRIPT** e **VUE.JS**, com as seguintes funcionalidades:
- Cadastro de usuários;
- Cadastro do estoque;
- Sistema de empréstimo;
- Relatórios gerais.
